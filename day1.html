🚀 Getting Started with AI & GitHub

Day 1 · Aug 17, 2026

Day 1 was about getting my tools in order — setting up an AI coding partner, understanding what GitHub actually is, and shipping something real instead of just reading about it.

  • Set up Claude AI and learned how to prompt it effectively — explaining what I wanted clearly, reviewing what it built, and asking follow-up questions instead of accepting the first answer.
  • Learned the fundamentals of GitHub and version control — what a repository is, why commits matter, and how a public repo lets anyone view or reuse the code.
  • Built my first browser game, "Basketball Shooter", from scratch using HTML, CSS, and JavaScript, with Claude helping me structure the game logic and scoring.
  • Uploaded the project to GitHub manually for the first time — creating a repository through the website and dragging the files in, rather than using Git commands (that came on Day 2).
  • Got comfortable with the basic AI-assisted workflow: describe the goal, let Claude write the first draft, then test it in the browser and ask for fixes.
